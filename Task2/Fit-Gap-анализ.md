## 3. Основные выявленные пробелы

По результатам Fit/Gap-анализа видно, что существующие системы закрывают базовые процессы компании, 
но не поддерживают полный процесс цифрового аукциона.

Основные пробелы:

* в ИС «Алмазы» требуется добавить отдельный процесс отбора камней для цифрового аукциона;
* в ИС «Логистика» требуется добавить сценарий перевозки камней в лабораторию и обратно;
* в ИС «Аукцион» требуется добавить публикацию цифровых материалов по алмазам;
* требуется реализовать интеграцию между ИС «Лаборатория» и ИС «Аукцион» для передачи цифрового описания камней;
* требуется реализовать передачу данных из ИС «Лаборатория» в ИС «Бухгалтерия» для актирования услуг;
* требуется добавить сквозной контроль статусов по каждому камню;
* на промежуточном этапе часть данных будет передаваться вручную через Excel-шаблоны;
* публикация материалов через внешнее облако является временным решением и требует настройки контроля доступа.

В промежуточном решении эти пробелы можно закрыть регламентами, Excel-шаблонами и ручным контролем. 
В целевом решении эти участки должны быть автоматизированы через доработку ИС и интеграции между ними.
